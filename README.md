# CMEE Coursework

Coursework for Computing Bootcamp (UNIX, shell scripting & Git).

## Project structure
- code/ : scripts and answers
- data/ : supplied input files
- results/ : generated outputs (not committed)
- sandbox/ : disposable tests (not committed)

## Usage
- Bash - no additional UNIX tools needed.
- Run scripts from 'code/'.

## Data
- '/fasta/': supplied sequence files.
- '/temperatures/': supplied comma-delimited files.
- '/tab-example.tsv': small tab-delimited test file I created.

## AI use
- Tool - Claude: explaining commands (such as `>&2`), interpreting error messages, help with shell quoting, test suggestions.
- Resources - Stack Overflow: understand commands (such as `tr -d`, `bc -l` and `\n`).
